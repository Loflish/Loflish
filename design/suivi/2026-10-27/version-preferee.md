# La version préférée de Tom (27 octobre 2026)

Ce que Tom voit et adore : la constellation sur le fond en feutre peint, l'eau vivante, le logo brodé lisible sans halo.
Capture : `version-preferee-constellation.webp`.

Pour la rouvrir exactement : `npm run dev -- --port 5174`, puis
http://127.0.0.1:5174/?fond=feutre&eau=1&entree=toujours#/

- `fond=feutre` : le fond en feutre de laine peint (public/hd/essais/fond-feutre-*.webp)
- `eau=1` : l'eau qui bouge (src/engine/eau.ts, réglages par défaut du 26 octobre)
- `entree=toujours` : l'animation d'accueil à chaque visite

Le code de cette version est figé dans l'étiquette git `version-preferee-2026-10-27`.
